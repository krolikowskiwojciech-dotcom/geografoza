# Geografoza

Rodzinna aplikacja do nauki geografii (klasa 6), na wzór Biologozy: lekcje z podręcznika z nagraniami, ćwiczeniami
i ściągą, kartkówki ze zdjęć, poprawka z wyjaśnieniem po każdym błędzie i wynik wysyłany rodzicowi.

https://krolikowskiwojciech-dotcom.github.io/geografoza/

Instrukcja pracy: `CLAUDE.md`, format zestawów: `ZESTAWY.md`.
